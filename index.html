Pengaturan API Keys

Gunakan koma untuk memasukkan lebih dari satu kunci (sebagai fallback).

Cara mendapatkan Gemini API Key?
  1. Kunjungi Google AI Studio.
  2. Login menggunakan Akun Google Anda.
  3. Klik menu Get API key di sebelah kiri atas.
  4. Klik tombol biru Create API key.
  5. Setelah jadi, klik tombol Copy atau salin teks kuncinya lalu tempel ke kolom di atas.

Digunakan sebagai alternatif Tier-3 jika Limit Request Gemini habis.

Cara mendapatkan Groq API Key?
  1. Kunjungi Groq Console.
  2. Login atau daftar akun baru Anda.
  3. Pilih menu API Keys di sidebar kiri layar.
  4. Klik tombol hitam Create API Key di pojok kanan, beri nama (bebas).
  5. Salin kuncinya (biasanya diawali gsk_) lalu tempel ke kolom di atas.
